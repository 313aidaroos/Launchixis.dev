# Launchixis brand

Cut from the official reference photo. The lockup is the photographed ink on a transparent ground. Nothing here was redrawn, and there is no SVG.

The photographed lockup is 590×70 and the mark is 66×67. Both are below the kit minimums, so `logo-full.png`, `logo-full-white.png`, `mark.png` and `mark-white.png` were scaled up with a Lanczos resample only (about 1.74× for the lockup, about 7.6× for the mark). White files are the same alpha filled with pure white.

## Which file to use

- `logo-full.png` — horizontal lockup (mark on the left, name on the right) on light backgrounds.
- `logo-full-white.png` — the same lockup on dark backgrounds. The header uses this one.
- `mark.png` — the icon alone, on light backgrounds.
- `mark-white.png` — the icon alone, on dark backgrounds.
- `favicon.ico` and `favicon-32.png` — browser tab.
- `apple-touch-icon.png` — Apple touch icon, 180px.
- `icon-192.png` and `icon-512.png` — installed-app icons.
- `og-image.png` — link previews, 1200x630. The lockup is centered on a plain background.
- `brand.json` — name, domain, tagline, colors, and these file paths.

Tab, touch and app icons put the white mark on the site background (`#080E25`) so the icon stays visible. The mark files themselves stay transparent.

Colors in `brand.json` come from the cutout. The ink is a single near-white, so `primary`, `accent` and `text` are that ink. `background` is the flat site canvas the white ink sits on.
